# 參與貢獻 (Contributing)

[English](#english) | **繁體中文**

感謝您對 CodeMask 的感興趣！這是一個展示 macOS 安全開發實踐的個人專案，非常歡迎任何形式的貢獻。

## 如何參與

為了保持代碼品質與 `prod` 分支的穩定，請遵循以下流程：

1. **搜尋既存問題**：在開新 Issue 前，請先檢查是否已有重複的問題。
2. **使用範本**：回報 Bug 請使用 [Issue 範本](.github/ISSUE_TEMPLATE/bug_report.md)。
3. **分支管理**：從 `prod` 分支建立您的特性分支 (`feature/your-feature`)。
4. **代碼風格**：請遵循 [Swift API Design Guidelines](https://www.swift.org/documentation/api-design-guidelines/)。
5. **提交 PR**：描述變更動機，並確保所有 CI 檢查均已通過。

## English

Thank you for your interest in CodeMask! This is a personal project showcasing macOS security development practices, and contributions of any kind are welcome.

## How to Contribute

To maintain code quality and the stability of the `prod` branch, please follow these steps:

1. **Search Existing Issues**: Check if your issue has already been reported.
2. **Use Templates**: For bug reports, please use the [Issue Template](.github/ISSUE_TEMPLATE/bug_report.md).
3. **Branching**: Create your feature branch (`feature/your-feature`) from the `prod` branch.
4. **Code Style**: Adhere to the [Swift API Design Guidelines](https://www.swift.org/documentation/api-design-guidelines/).
5. **Submit PR**: Describe the motivation behind your changes and ensure all CI checks are passing.
