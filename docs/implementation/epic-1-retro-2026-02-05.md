## 3. Retrospective Insights

### ✅ What Went Well (Successes)

1.  **Performance Breakthrough:** The implementation of the **Combined Regex (Single Pass)** strategy reduced masking latency for 50KB payloads from ~2.1s to **0.021s**, far exceeding the NFR requirement of <100ms.
2.  **Security Architecture:** The `SecureBuffer` implementation successfully utilized `posix_memalign` and `mlock` to guarantee sensitive data is never swapped to disk, establishing a solid security foundation.
3.  **Restoration Fidelity:** The restoration loop achieved 1:1 bit-for-bit accuracy, ensuring that developers can trust the tool to restore their code exactly as it was.
4.  **Resource Safety:** The team adopted strict resource management patterns (e.g., using `defer` for `CGEvent` taps), preventing memory leaks and crashes.

### ⚠️ Challenges & Learnings

1.  **macOS Permission Monitoring:** The team discovered that macOS does not provide proactive notifications for accessibility permission changes.
    *   *Solution:* Implemented a polling mechanism (Timer) to ensure UI state consistency.
2.  **Simulated Paste Stability:** The `Cmd+Opt+V` trigger introduced modifier key interference when simulating `Cmd+V`.
    *   *Solution:* Added a Stabilization Delay (~100ms) to ensure reliable pasting.
3.  **Clipboard Race Conditions (TOCTOU):** The team identified a theoretical risk where malicious apps could sniff the clipboard during the brief masking/restoration window.
